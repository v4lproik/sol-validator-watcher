Operator workflow

From signal to answer in one surface.

Start with process readiness and validator state, diagnose against network context, then verify recovery through clean polling rounds.

  1. 1

    Detect

    Find what needs attention.

    Health, readiness, and watched-validator state make the first failure visible without searching across tools.

  2. 2

    Diagnose

    Compare it with the network.

    Vote lag, root lag, skip rate, stake, source provenance, and provider outcomes keep the signal in context.

  3. 3

    Verify

    Observe a clean recovery.

    Five consecutive clean polling rounds restore readiness while failed modes and stale snapshots stay explicit.
