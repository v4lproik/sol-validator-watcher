Pull the image from GHCR

The workflow publishes branch, tag, SHA, and latest tags to GitHub Container Registry.

Pull

docker pull ghcr.io/v4lproik/sol-validator-watcher:latest

Run

docker run --rm \
  -p 8000:8000 \
  -v "$(pwd)/config:/app/config:ro" \
  ghcr.io/v4lproik/sol-validator-watcher:latest \
  --config /app/config/config.devnet.yaml
