Built for operators

Actionable signals over generic telemetry

The exporter focuses on the decisions Solana operators actually make: who is lagging, who is skipping, how watched validators compare to the rest of the network, and where the next leader pressure sits.

Ready on day one

Profiles, dashboards, and pages already wired

Devnet, Surfpool, and external-validator profiles are included. Grafana dashboards are provisioned. The GitHub Pages site publishes both the landing page and the generated coverage report from the same workflow.

Keeps secrets out of YAML

Split config with Figment and TOML

Validator connection details live in a dedicated TOML file with environment expansion, while the main YAML stays focused on watcher behavior and operator labeling.

Operator-first, label-aware fleet monitoring

The watcher exports network-wide, watched-validator, and custom-scope metrics from the same collection pass. That makes the dashboards useful immediately, not after weeks of panel cleanup.

Watched vs network baselines Track your validator set against full-network and non-watched comparisons.
Scope breakdowns Use `category:value` labels to slice fleets by operator, region, validator class, or customer group.
Failure-aware collection Optional RPC enrichments degrade cleanly while the core metrics stay online.

Coverage is part of the site, not an afterthought

The Pages build publishes the landing page at the root and the generated `cargo llvm-cov` report under /coverage/. That keeps engineering hygiene visible without making the homepage feel like a raw artifact dump.

Ship the image straight from GHCR

The container workflow publishes branch, tag, SHA, and `latest` tags to GitHub Container Registry on pushes to the default branch and release tags.

Pull the latest image

docker pull ghcr.io/v4lproik/sol-validator-watcher:latest

Run against a config file

docker run --rm \
  -p 8000:8000 \
  -v "$(pwd)/etc:/app/etc:ro" \
  ghcr.io/v4lproik/sol-validator-watcher:latest \
  --config /app/etc/config.devnet.yaml

main
latest
sha-<commit>
