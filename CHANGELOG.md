# Changelog

Changes are recorded in the owning module's changelog. Use the [README module index](README.md#modules) and the [repository ownership table](.omp/skills/sol-validator-watcher/resources/changelog-and-modules.md#module-ownership) to find the source entry points and correct owner. Update every affected module when a change crosses boundaries; source-tree reorganizations remain in their owning module histories.

New entries go under `Unreleased`. At release time, move those entries under a version and date without combining module histories.
