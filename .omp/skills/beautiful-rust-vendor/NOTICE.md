# Vendored Rust Skill Provenance

The following project skills are vendored from the Beautiful Rust project:

- `.omp/skills/rust-best-practices/`
- `.omp/skills/rust-review/`
- `.omp/skills/rust-port/`

Source: `https://github.com/morganlinton/BeautifulRust`

Pinned upstream revision:
`a9cdcfa94d1330c0d41c7f67764c5f7786fbb71d` (2026-10-30)

Vendored scope: each skill's `SKILL.md` and the `rust-best-practices/references/`
digests. Upstream eval cases, plugin manifests, benchmarks, scripts, and lint
configuration are intentionally excluded. Repository-specific command and
architecture differences are defined in
`.omp/skills/sol-validator-watcher/resources/rust-code-quality.md`.
